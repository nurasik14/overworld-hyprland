- Fallback sounds `assets/gen/sounds/*.wav` (60 files, 24 kHz mono, 1.2 MB) synthesized by `tools/assetforge/make_sounds.py` (numpy; original).
- Verified: dry-run for many ids, volume maths with a custom config, no-mc fallback (`OW_MC_DIR=/nonexistent`), `--list`; **sounds:false really blocks playback** and sounds:true really invokes the player — proven with a shim `pw-play` on PATH that only logs (nothing audible was ever played; real pw-play never invoked). Bug found+fixed on the way: jq `false // true` is `true`, so sounds:false was ignored until `has("sounds")` was used.
